# Achter het lied

Een luisterdemo van Bernard Donners, gemaakt met AI-assistent Eva. Negen nummers met vooraf gemaakte verhalen, verteld door een AI-stem.

Luisteren: https://berndonn.github.io/achter-het-lied-demo/

Deze statische site gebruikt alleen HTML, JavaScript en audio. Geen account, backend of installatie nodig.

Muziekrechten blijven bij de betreffende rechthebbenden. Deze repository verleent geen aanvullende toestemming voor hergebruik van de opnamen.
